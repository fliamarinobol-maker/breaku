# BreakU

Prototipo web controlado para la cafetería de planta baja del campus Montes de la Facultad de Ciencias Económicas y Financieras (UMSA).

## Recorrido sugerido para la exposición

1. Mostrar el aforo disponible.
2. Crear una reserva o agregar un producto y confirmar el pedido.
3. Enseñar el QR generado y el seguimiento del pedido.
4. Abrir **Panel de demo** y avanzar el pedido hasta **Listo**.
5. Cambiar el aforo a **Lleno** para mostrar las alternativas cercanas.

Los datos son simulados y no se almacenan.
